# strattV1

This repository contains a filtered extraction of the Ableton Push 1-specific code from the upstream project `git-moss/DrivenByMoss` (release 19.2.2).

Scope kept:
- Push version identification (`PushVersion`)
- Push 1 controller definition
- Push 1 display behavior
- Bitwig extension wiring for Push 1
- minimal Push 1 configuration surface

This is intentionally limited to the Push 1 subset and does not include the full general-purpose controller framework or Push 2/3 code.
